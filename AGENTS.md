# Недельный отчёт ООО «Рога и Копыта»

Следуй [поручению](06_context_capsules/weekly_launch_update.md). Для черновика используй перечисленные в нём документы. Пример в `07_runs/example/` предназначен для сравнения после выполнения задания.

Сохрани свой отчёт в `07_runs/practice/output.md`. Если этот черновик уже есть, создай отдельную папку, например `07_runs/practice-2/`. Ссылки в отчёте должны открывать исходные документы из сохранённого файла. Надя Орлова проверяет черновик перед отправкой.
