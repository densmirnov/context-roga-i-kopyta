# Недельный отчёт ООО «Рога и Копыта»

Следуй [поручению](05_context_capsules/weekly_launch_update.md). Для черновика используй перечисленные в нём документы. Пример в `06_runs/example/` предназначен для сравнения после выполнения задания.

Сохрани свой отчёт в `06_runs/practice/output.md`. Если этот черновик уже есть, создай отдельную папку, например `06_runs/practice-2/`. Ссылки в отчёте должны открывать исходные документы из сохранённого файла. Надя Орлова проверяет черновик перед отправкой.
