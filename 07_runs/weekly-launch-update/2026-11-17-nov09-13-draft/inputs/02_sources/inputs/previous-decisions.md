# Решения прошлого цикла

Дата встречи — 6 ноября 2026 года.

1. Для ранних демонстраций использовать только вымышленную среду ООО «Рога и Копыта».
2. Не показывать исходные клиентские заметки и реальные имена.
3. Не строить новую платформу до проверки трёх сценариев с помощью действующих инструментов.
4. Контрольная дата 90-дневной проверки остаётся 6 февраля 2027 года.
5. Генеральный директор принимает решение о внешнем показе после проверки того, какие данные можно использовать и кто их увидит.

## Открытое решение
