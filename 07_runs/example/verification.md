# Сверьте свой отчёт

[Откройте пример отчёта](output.md) после своего запуска. Проверьте выводы по исходным документам. Для одной спорной фразы запишите вывод, источник, статус и нужную правку.

1. **Даты.** 6 февраля 2027 года — утверждённая контрольная дата. Выпуск к 23 января 2027 года пока предложили. На 25 ноября отдел продаж запросил показ. [Утверждённая цель](../../02_sources/inputs/approved-launch-goal.md) и [заметки недели](../../02_sources/inputs/current-week-notes.md).
2. **Показ клиентам.** Ответственного за проверку данных ещё не назначили. Для внешнего показа сначала нужна проверка данных и прав доступа, затем решение генерального директора. Вымышленная среда — одно из условий раннего показа. [Заметки недели](../../02_sources/inputs/current-week-notes.md) и [решения прошлой встречи](../../02_sources/inputs/previous-decisions.md).
3. **Числа.** Есть пять обезличенных наблюдений. Число проведённых демонстраций и подтверждённых запросов на пилот в материалах не указано. [Наблюдения клиентов](../../02_sources/inputs/customer-signals.md).
4. **Риски и решения.** Рисков до трёх. У каждого есть причина, возможное последствие и предложение о следующих шагах. Вопросы к руководителю вынесены отдельно.

Пример — черновик. Перед отправкой Надя проверяет факты и формулировки.
