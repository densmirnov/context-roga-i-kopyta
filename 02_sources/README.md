# Документы, на которые опирается отчёт

- [`inputs/`](inputs/) — утверждённая цель, заметки недели, решения прошлой встречи и обезличенные сигналы клиентов.
- [`company/`](company/) — письмо генерального директора, первоначальная цель и клиентские заметки.

Чтобы понять, что подтверждает документ и когда он действует, откройте [список источников](../01_cards/01_use_case_and_sources.md). Исходный путь, версия и контрольная сумма каждого перенесённого файла указаны в [`SOURCE_PROVENANCE.json`](../SOURCE_PROVENANCE.json).

Для новой недели добавьте отдельные исходные документы. Укажите, какие версии войдут в поручение, и сохраните их рядом с черновиком. Если сведения передали устно, запишите их в отдельном файле с автором, датой и статусом.
