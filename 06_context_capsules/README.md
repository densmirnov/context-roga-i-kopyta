# Какое поручение дать агенту

- Откройте [поручение за 9–13 ноября](weekly_launch_update.md), чтобы увидеть, какие файлы нужны и что должно быть в черновике.
- Сверьтесь с [порядком подготовки, версия 0.2](workflow-contract.md), если нужно проверить приоритет источников или понять, когда остановить работу.
- Посмотрите [первую версию, 0.1](workflow-contract-v0.1.md) и [журнал отчётов](../07_runs/weekly-launch-update/run-log.md), чтобы увидеть, как менялся порядок работы.

Для новой недели сначала соберите документы и проверьте, какие решения действуют. Затем обновите [список файлов для отчёта](../05_current_context/weekly_launch_inputs.md) и поручение. Прежние версии лежат рядом с черновиками, для которых их использовали.

Дополнительные материалы оригинала: [разбор конфликта источников](https://github.com/densmirnov/acme-labs/blob/a87a7fe547b1f8d61c6c00dbb186427dceda5a4d/workflows/weekly-launch-update/examples/source-conflict.md), [проверка процесса](https://github.com/densmirnov/acme-labs/tree/a87a7fe547b1f8d61c6c00dbb186427dceda5a4d/evaluations/weekly-launch-update) и [инструкция для повторяемой подготовки](https://github.com/densmirnov/acme-labs/blob/a87a7fe547b1f8d61c6c00dbb186427dceda5a4d/skills/weekly-launch-update/SKILL.md).
