# Как устроен пример

Откройте [карточку контекста](01_cards/CONTEXT.md). В ней те же шесть полей, которые вы заполняете в пятницу. Для передачи коллеге в субботу подготовьте карточку, поручение, исходные документы, черновик и запись проверки.

| Где | Что найти |
| --- | --- |
| [01_cards](01_cards/CONTEXT.md) | Заполненная карточка контекста |
| [02_sources](02_sources/inputs/) | Четыре исходных документа |
| [03_representations](03_representations/weekly_signals.md) | Сводка заметок со ссылкой на оригинал |
| [04_canonical_context](04_canonical_context/) | Правила компании и требования к отчёту |
| [05_current_context](05_current_context/launch_state.md) | Состояние запуска на конец недели и открытые вопросы |
| [06_context_capsules](06_context_capsules/weekly_launch_update.md) | Поручение и список файлов для отчёта |
| [07_runs](07_runs/example/) | Один пример черновика и памятка для ручной сверки |

В [конструкторе контекстного слоя](https://densmirnov.com/nord/), навыке для агента и этом примере одна карточка с шестью полями. Для своей задачи сначала создайте `01_cards/CONTEXT.md`, затем добавьте нужные разрешённые исходники в `02_sources/`. После этого дайте задачу агенту.

[Перейти к заданию в Codex](README.md#сделать-отчёт).
